# Prototype jetable — kit événement (MonAsso)

**À essayer au téléphone : https://yoannf57.github.io/monasso-prototype/**

Prototype cliquable pour faire tester les parcours à des parents et au bureau d'une association de parents d'élèves.
Toutes les données sont **fictives** (APE « Les Coquelicots »). Ce qu'on saisit reste dans le navigateur du testeur : rien n'est envoyé nulle part.

- Espace bureau : barre en bas (Aujourd'hui, Événements, Réunions, L'asso).
- Espace parent : le lien envoyé aux parents, par exemple `#inscription/vide-grenier`.
- Bouton « Démo » du bandeau noir : changer de membre du bureau, voir l'espace parent, réinitialiser.

Ce dépôt ne contient que les fichiers du prototype, publiés automatiquement. Il ne doit pas être indexé par les moteurs de recherche.
