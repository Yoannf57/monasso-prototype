# Prototype jetable — kit événement (MonAsso)

**À essayer au téléphone : https://yoannf57.github.io/monasso-prototype/**

Prototype cliquable pour faire tester les parcours à des parents et au bureau d'une APE avant d'écrire la vraie application.
Toutes les données sont **fictives** (APE « Les Coquelicots »). Ce qu'on saisit reste dans le navigateur du testeur : rien n'est envoyé nulle part.

Le bouton « Écrans » du bandeau noir mène aux 4 écrans ; « Réinitialiser la démo » efface les saisies.
Tests : `node --test tests/`.
